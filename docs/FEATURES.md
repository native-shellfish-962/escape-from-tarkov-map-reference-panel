# Escape from Tarkov Map Reference Panel — feature reference

The Escape from Tarkov map reference panel workflow separates map layers from location notes and session planning. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Map layers | A dedicated section for map layers and the configuration details associated with that area. |
| Location notes | A dedicated section for location notes and the configuration details associated with that area. |
| Session planning | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
